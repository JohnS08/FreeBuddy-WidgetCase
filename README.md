# FreeBuddy Case

FreeBuddy Case — Android-приложение для Huawei FreeBuds 3i, 4i и 5i.

Приложение показывает заряд левого и правого наушника и кейса, позволяет управлять основными функциями наушников и содержит компактный виджет только для заряда кейса. При снижении заряда ниже заданного порога приложение может показать уведомление.

## Возможности

- просмотр заряда наушников и кейса;
- компактный виджет кейса на главном экране;
- уведомление о низком заряде кейса;
- управление шумоподавлением и режимом прозрачности;
- настройка действий двойного касания и удержания;
- низкочастотная фоновая проверка для экономии энергии;
- русский интерфейс.

## Поддерживаемые модели

- Huawei FreeBuds 3i;
- Huawei FreeBuds 4i;
- Huawei FreeBuds 5i.
